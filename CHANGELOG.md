# Changelog

All notable changes to Character Counter Pro. The manifest version and the top
entry here must match before anything is uploaded to the Chrome Web Store.

## 1.0.0 - 19 September 2026

First public release.

- Popup counter with live characters, characters without spaces, words,
  sentences, paragraphs, lines, reading time and speaking time.
- Eight platform limit presets: X and Twitter, Instagram captions, LinkedIn
  posts, meta descriptions, SEO titles, SMS, Facebook posts and YouTube titles,
  each with a remaining count and an over-limit state.
- Draft memory so text survives closing and reopening the popup, using
  chrome.storage.local.
- Page checker that reads the active tab's title and meta description, reports
  character count and an approximate pixel width, and renders a Google style
  preview with realistic truncation.
- Options page for the highlighted preset, reading and speaking speed, draft
  memory and theme.
- Four icon sizes generated by tools/make_icons.py.
- Unit tests for the counting logic in tests/count.test.js.
